# Design System

Handbook ini menentukan cara membangun dan mendokumentasikan design system. Token, brand, komponen, dan pola aktual harus menjadi milik masing-masing produk dan disimpan di repo produk, misalnya `docs/design-system/`.

- [Prinsip design system](design-principles.md)
- [Template design system proyek](design-system-template.md)

Target baseline produk web: **WCAG 2.2 Level AA**, kecuali pemilik aksesibilitas menetapkan target yang lebih tinggi atau menjelaskan pengecualian dengan mitigasi. Aksesibilitas adalah syarat penerimaan produk, bukan polish setelah selesai.
