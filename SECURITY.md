# Security Policy

Status: repository security contact and private reporting route must be confirmed before this repository is published as an organizational standard. This is a release blocker.

Please do not report vulnerabilities in public issues or pull requests. Before publication, the maintainer must enable GitHub private vulnerability reporting for this repository or add another approved private security contact/process here. Until then, do not include exploit details, secrets, or personal/customer data in public communication.

The handbook is a documentation project. Security reports about systems that adopt it must go to the owner of those systems through their approved reporting channel, not to this repository.
