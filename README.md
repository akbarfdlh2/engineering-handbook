## Cakupan

Handbook ini mendefinisikan baseline lintas proyek. Setiap repo tetap mendokumentasikan stack, arsitektur, brand, risiko, dan prosedur lokalnya. Terapkan kontrol sesuai klasifikasi risiko data dan layanan; standar ini bukan sertifikasi kepatuhan hukum atau industri.

## Tingkat aturan

- **MUST**: kontrol minimum wajib. Penyimpangan memerlukan persetujuan pemilik risiko, mitigasi, dan tanggal kedaluwarsa.
- **SHOULD**: rekomendasi kuat. Jika tidak dipakai, catat alasan dan trade-off.
- **MAY**: pilihan yang dapat dipakai bila sesuai konteks.

Untuk standar yang dapat berubah, catat versi referensi dan tanggal tinjau. Lihat [cara menerapkan handbook](00-governance/README.md).
